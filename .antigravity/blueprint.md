# Project Blueprint: Jobber.ai

## Vision & Goals
Jobber.ai is an AI-powered career agent platform designed to automate and optimize the job search process. The landing page serves as the high-impact entry point to attract talent and showcase key AI differentiators.

## Core Features (Roadmap)
- [x] Landing Page (Phase 1)
- [ ] Precision Job Matching (Phase 2)
- [ ] Automated Resume Customization (Phase 3)
- [ ] AI Career Agent Chat (Phase 4)
- [ ] Referral & Alumni Insights (Phase 5)

## Technology Stack
- **Framework**: Astro 5.x (SSG/SSR)
- **Styling**: Tailwind CSS
- **i18n**: Astro Native Internationalization
- **Theme**: Light/Dark mode with custom `#97dd1e` primary color
- **Version Control**: Git

## Project Structure (Blueprints)
- `/src/components`: UI Atomic components (Navbar, Hero, FeatureCard, etc.)
- `/src/layouts`: Page shells (MetaData, i18n support, Global CSS)
- `/src/pages`: Route-based entry points (Localized folders)
- `/src/styles`: Design tokens and global utility styles
- `/.antigravity`: Project metadata and development history
